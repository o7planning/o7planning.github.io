Surface Hierarchy (Surface Namespace)

The Surface Namespace defines the fundamental layers of your application. It hosts all content, manages layouts, and creates visual depth through overlapping surface levels.

1. Large Surface Layers

Tokens in the faColors.surface.xxx group are designed for high-area components such as Scaffold Base, Containers, Cards, or Dialogs.

2. The "Foundational Trio" Rule

Since Surfaces consist of large color areas, coordination between text and borders is crucial:

  • Text & Icons: Must use faColors.text.xxx to ensure optimal readability.
  • Borders: Use faColors.border.subtle for gentle content separation (Cards) or faColors.border.strong for solid structural outlines.
THE GOLDEN RULE: When using background colors from faColors.surface.xxx, always pair them with faColors.text.xxx and faColors.border.xxx. This set is calibrated to ensure safe contrast ratios across all themes.

3. Visual Elevation (Z-Index)

The system provides levels from low to high. Use surface.low for recessed components and surface.high for elements that need to "float" above, creating a clear visual hierarchy.

Technical color values are available in the Token Docs tab.
