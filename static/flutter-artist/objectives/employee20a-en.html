Hierarchical Filters & Default Value Initialization

This example demonstrates how to manage Multi-selection in a parent-child relationship and automatically initialize Default Values for search criteria.

  • Smart Default Selection: When the FilterModel loads, it automatically selects the first available Company and subsequently selects all Departments within that company by default.
  • Dynamic Re-initialization: Every time the user changes the Company selection, the system reactivates the specifyDefaultValueForMultiOptTildeCriterion logic for the Child Block, ensuring the Department list is always populated with a valid initial state.
  • Multi-Select Hierarchy: Combines a single-selection Parent (Company) with a multi-selection Child (Departments), showcasing how FlutterArtist handles mixed selection modes in a cascading chain.

Technical Focus: Mastering the specifyDefaultValue lifecycle to create intuitive, zero-click search experiences.
