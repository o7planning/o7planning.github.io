## Color System Overview

The FlutterArtist Color System is built for developer intuition.
  Focus on the clear relationship between **Fill** (Background),
  **Ink** (Foreground/Content), and **Stroke** (Border).

### 1. Visual Logic (Light Theme)

In Light Theme, structural surfaces remain bright, while interactive actions and typography use deep/dark tones.

### 2. Three Action Design Patterns

To maintain ecosystem consistency, use one of the following implementation patterns for interactive components:

* **Pattern 1: High Emphasis (Solid Style)**<br>
    Use `faColors.action.fill.primary` (Deep) + `faColors.action.ink.onPrimaryFill` (Bright).<br>
    *Best for: Primary buttons, FABs, and critical system triggers.*

  * **Pattern 2: Minimalist (Ghost Style)**<br>
    No Background + `faColors.action.ink.primary` (Deep).<br>
    *Best for: Secondary actions, toolbar icons, and flat buttons.*

  * **Pattern 3: Soft Emphasis (Reverse Style)**<br>
    Use `faColors.action.fill.reversePrimary` (Bright) + `faColors.action.ink.primary` (Deep).<br>
    *Best for: Selected states in sidebars/menus, chips, and subtle status indicators.*

> **Technical Note:** `reverse` tokens (e.g., `faColors.action.fill.reversePrimary`) are programmatically generated by shifting lightness toward the edge (~95% in Light Mode). This ensures a clean, subtle background that perfectly highlights dark content while maintaining brand identity.

*Note: The system automatically handles Dark Mode by inverting the Light/Dark logic.*
