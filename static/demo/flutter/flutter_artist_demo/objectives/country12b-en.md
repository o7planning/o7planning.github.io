# Visual Sorting with ChipSortPanel

This example enhances the sorting experience by introducing the **ChipSortPanel**, offering a more interactive and visual approach to data organization compared to traditional dropdowns.

* **High-Visibility UI:** Unlike dropdown menus, **ChipSortPanel** displays all available sorting criteria as interactive chips. This reduces the cognitive load by making all options visible at a glance.
* **One-Tap Interaction:** Users can toggle between **Ascending**, **Descending**, and **None** states by simply tapping the chips. Each tap reactively updates the **SortModel**, triggering either a local reorder or a server query.
* **Modern UX Pattern:** Ideal for mobile-first designs or e-commerce galleries, this component provides immediate visual feedback through active states and arrow indicators, keeping the user perfectly oriented.
