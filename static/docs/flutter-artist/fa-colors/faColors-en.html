Color System Overview

The FlutterArtist Color System is designed to follow the natural intuition of developers. You only need to understand the relationship between Fill (Background), Ink (Content), and Stroke (Border).

1. Visual Logic (Light Theme)

In Light Theme, surfaces are generally bright, while actions and typography are deep/dark.

2. Three Action Strategies

When building interactive components (Buttons, Menus, Chips), choose one of these patterns:

  • Pattern 1: High Emphasis (Solid)
    Use fill.primary (Dark) + ink.onPrimaryFill (Light).
    Best for: Primary buttons, FABs, critical triggers.
  • Pattern 2: Minimalist (Ghost)
    No Background + ink.primary (Dark).
    Best for: Secondary actions, flat buttons, toolbar icons.
  • Pattern 3: Soft Emphasis (Reverse) - RECOMMENDED FOR NAV
    Use fill.reversePrimary (Light) + ink.primary (Dark).
    Best for: Selected menu items, sidebars, chips, status banners.
Technical Note: The reverse tokens are calculated by pushing the lightness toward the edge (~95% for Light theme) to provide a soft background for dark text while preserving the brand hue.

Note: For Dark Theme, the Light/Dark logic is automatically reversed by the system.
