Basic Data Block Example

This example demonstrates the core usage of a single Data Block to manage and synchronize data across different UI components.

  • BlockItemsView (Left): Renders a scrollable list of records. It listens to the Block's state to highlight the currently active item.
  • BlockItemDetailView (Right): Displays the detailed attributes of the selected record. It automatically updates whenever the Block's current index changes.
  • State Synchronization: Shows how the Next and Previous actions update the Block's pointer, triggering a reactive UI update on both views.

Technical Focus: Mastering the communication between a Block and its dependent View components.
