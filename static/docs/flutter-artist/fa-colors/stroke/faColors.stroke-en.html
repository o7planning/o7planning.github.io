Information & Content Hierarchy (Typography Namespace)

The Typography Namespace is more than just a collection of colors. It defines the "role" and "weight" of information within the UI, allowing users to quickly scan and grasp key content in data-heavy environments.

1. Key Semantic Roles

Each token in context.faColors.ink.xxx is crafted for a specific purpose:

  • Primary: Reserved for main headlines and critical content requiring immediate attention.
  • Secondary: Used for descriptions, sub-headers, or supporting body text.
  • Label: Dedicated to input field labels, table headers, or small metadata.
  • Muted: For captions, timestamps, or disabled states that still require legibility.

2. The "Surface Partnership" Rule

To achieve optimal aesthetics and contrast, the Typography Namespace is designed to thrive on foundational background layers.

SURFACE RESTRICTION: These Typography tokens are optimized exclusively for faColors.surface.xxx layers (Base, Container, Low, High). Never use them for buttons or chips; instead, utilize faColors.action.ink.xxx for action-based elements.

3. Semantic Status Text

Beyond hierarchy, Typography provides status colors (Success, Warning, Danger, Info). These colors convey emotion and urgency at a glance, providing context even before the user reads the actual text.

Technical Hex values for each text type are available in the Token Docs tab.
