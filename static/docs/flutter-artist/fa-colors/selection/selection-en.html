Visual Language for Interaction (Selection Namespace)

In complex data management applications, clearly defining where the user is and what they have selected is crucial. The Selection Namespace is specifically designed to handle row interactions in Data Tables or Lists, ensuring a consistent and professional feedback loop.

1. When to use the Selection Namespace?

Imagine building a Product Catalog or an Order List. When a user hovers over a row, clicks to select one or multiple items, or uses arrow keys to navigate – that is precisely when you should invoke context.faColors.selection.

2. Supported Interaction States

  • Normal State: The default background color when no action is taken.
  • Selected State: Highlights items that have been chosen and persisted in memory.
  • Current State (Focus): Indicates the user's active cursor position, essential for keyboard navigation.
  • Feedback States (Hover & Pressed): Provides immediate visual cues during mouse or touch interactions.

3. The "Unified Trio" Rule (Surface - Text - Border)

A key strength of FlutterArtist is its group-based color coordination. For optimal aesthetics and contrast, always use tokens in their designated sets:

  • Background (Surface): Use faColors.selection.rowXXX to set the row's surface color.
  • Content (Text/Icon): Use faColors.selection.textXXX. These colors are calibrated to remain perfectly readable against their respective backgrounds.
  • Emphasis (Border): Use faColors.selection.borderXXX to create sharp outlines, making the item "pop" from the general layout.
ARTIST'S WARNING: Never mix faColors.selection with other color groups like faColors.text.xxx (designed for large Surfaces) or faColors.action.xxx (reserved for Buttons/Chips). Mixing these groups will break the contrast logic and compromise the UI's professionalism.

4. Advanced Design Philosophy

  • Text Coloring Logic: Selection text colors are designed to be calm and professional, unlike high-contrast Action buttons, ensuring readability for long periods without eye fatigue.
  • Border Mirroring: Combining a distinct border with the Selected background creates a "solid" identification frame, giving the selected row depth and a premium feel.
